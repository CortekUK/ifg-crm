# PROJECT_BRIEF.md

## Client
The International Football Group, referred to as IFG.

## Project Context
We are building a new public website alongside an existing IFG CRM. The CRM context is valuable because the website should connect naturally to the application/enquiry workflow. However, the public website must be treated as a premium client-facing experience, not as an extension of the internal CRM UI.

## Main Objective
Create a premium, conversion-focused website for ambitious football players and parents who are exploring football development, education pathways, international experiences, and structured player opportunities.

The new website should feel like a clear level-up from the current IFG website. It should preserve the strength of IFG's real brand, football imagery, partner credibility, and programme depth, while improving clarity, structure, conversion flow, mobile experience, and professionalism.

## Target Audiences
1. Ambitious football players aged roughly 15-23.
2. Parents evaluating safety, credibility, education, cost, and outcomes.
3. International students looking for UK, European, or international football education pathways.
4. Players interested in short-term experiences, camps, residencies, gap year programmes, university pathways, or elite club-linked experiences.
5. Potential partners, schools, clubs, academies, and institutions assessing IFG's credibility.

## Core Programmes
The website should support programmes including, where relevant:
- University Programme
- Masters Programme
- Gap Year Programme
- Residency Programme
- Summer Residency
- Spring Camp
- Juventus Experience

Programme naming and details should be checked against the existing site/client information before finalising copy.

## Primary Conversion Goal
The main goal is to generate qualified enquiries/applications that can be followed up through the CRM.

The ideal lead flow is:
Website enquiry/application form -> CRM lead record or webhook -> internal notification/email -> follow-up workflow.

If the form only sends an email and does not create a CRM lead, this must be stated clearly as a current limitation.

## CTA Hierarchy
Primary CTAs:
- Start Your Application
- Apply for a Programme
- Apply Now

Secondary CTAs:
- Explore Programmes
- Find Your Pathway
- Speak to the Team
- View Brochure

Existing user CTA:
- Player Login

Player Login should sit in the navigation or footer. It should not be the main website CTA.

## Website Structure
Recommended structure:
- Homepage / landing page: a focused conversion and routing page.
- Programmes index: helps users compare pathways.
- Dedicated programme pages: each programme behaves like a focused landing page.
- Enquiry/application form: connected to CRM or ready for CRM integration.
- Supporting proof sections: partners, testimonials, success stories, media, facilities, FAQs.

The homepage should not try to explain every detail. It should explain IFG quickly, build trust, segment visitors, and route users into the correct programme or application step.

## What the Current IFG Website Does Well
The existing website has useful strengths that should not be lost:
- real IFG branding
- real football and player imagery
- partner logos and institution credibility
- strong football/club atmosphere
- social proof and media presence
- established academy/education feeling
- clear programme categories

## What the New Website Must Improve
The new website must improve:
- clarity of user journey
- programme comparison
- CTA consistency
- mobile experience
- conversion flow
- visual polish
- credibility presentation
- form capture and CRM integration
- copy quality
- page hierarchy

## Strategic Positioning
IFG should be positioned as:
A premium international football education and development pathway helping ambitious players combine structured football development, academic progression, international experience, and credible opportunities.

Avoid positioning IFG as a simple football camp provider or a generic education consultancy.
